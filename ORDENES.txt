PASO 1 — HOSTING CON HTTPS  (el más importante: habilita push e instalar app)
  Quién: necesita el usuario (credenciales de Cloudflare o Vercel).
  Pasos:
    a. Elegir Cloudflare Pages o Vercel (los dos gratuitos).
    b. Subir la carpeta public/ (es estática; no hay build).
       · Cloudflare: dashboard → Workers & Pages → Create → Pages →
         Upload assets → arrastrar public/ → nombre "familia" → Deploy.
       · Vercel:  npx vercel --prod   dentro de la carpeta del proyecto
         (o subir public/ desde el dashboard).
    c. ANOTAR LA URL FINAL (ej. https://familia.pages.dev).
    d. Decírselo al asistente: hay que añadir esa URL en Supabase
       Dashboard → Authentication → URL Configuration → Redirect URLs
       (añadir https://TUURL/*) para que el enlace mágico siga funcionando.
    e. Probar en el móvil con HTTPS: login, y luego
       Ajustes → 🔔 Activar notificaciones (debe funcionar sin bloquearse).
    f. Avisar: al entrar por primera vez, el navegador ofrecerá "Instalar app".
